# AGENTS.md

## Project Overview
Analytics-training is a collection of training materials for students who are members of
a FIRST Robotics Competition (FRC) team. The students using these training materials
are in high school and most have never coded before. The students are learning Python
and Javascript so they can build and maintain applications for scouting at FRC
competitions.

## Code Style

### Python
1. Follow the Google Python Style guide, except for these exceptions:
   * Limit non-docstring Python statements to 88 characters.
   * Limit docstring lines to 80 characters, except for common exceptions such
     as long URLs.
2. Except for objects needed for type annotations that come from the typing and
   collections.abc modules, always import entire modules.
